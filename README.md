## Présentation

Velociter est le prototype en développement d'un jeu vidéo 2D roquelike, basé sur les déplacements et l'inertie. Beaucoup plus de contenus seront ajoutés plus tard.
Restez à l'affut des mises à jour qui vont suivre !
Ce projet est entièrement réalisé à la main, sans l'aide d'IA ou source externe.

## Supports

- Unity
- VS Code (C#)
- Paint.NET
- Git & GitHub
